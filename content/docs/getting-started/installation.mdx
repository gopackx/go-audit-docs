## Requirements

- Go **1.22** or later
- One of: GORM, Bun, or Ent (the core itself only needs `database/sql`)
- A supported database: PostgreSQL, MySQL, or SQLite

## Install Core

```bash
go get github.com/gopackx/go-audit
```

The core package depends only on the Go standard library — no external
drivers, no HTTP clients.

## Install ORM Adapter

Pick the adapter that matches your ORM. Each is a separate module so
you only pull in the ORM you actually use.

| ORM  | Package                                            |
| ---- | -------------------------------------------------- |
| GORM | `go get github.com/gopackx/go-audit/adapters/gorm` |
| Bun  | `go get github.com/gopackx/go-audit/adapters/bun`  |
| Ent  | `go get github.com/gopackx/go-audit/adapters/ent`  |

### Adapter versions

Adapter sub-modules are tagged independently from the core module
(Go's standard multi-module layout). When you pin a version, target
the adapter tag — for example `adapters/gorm/v1.1.0`, not just
`v1.1.0`:

```bash
go get github.com/gopackx/go-audit@v1.1.0
go get github.com/gopackx/go-audit/adapters/gorm@v1.1.0
```

If the adapter hasn't been tagged yet for a given release, pin to
`@master` to pick up the latest commit as a pseudo-version:

```bash
go get github.com/gopackx/go-audit/adapters/gorm@master
# go.mod rewrites this to e.g. v0.0.0-20260413120000-abcdef012345
```

## Supported Databases

| Database   | JSON Type | Index Strategy                   |
| ---------- | --------- | -------------------------------- |
| PostgreSQL | `JSONB`   | B-tree + GIN indexes on JSON     |
| MySQL      | `JSON`    | Inline B-tree indexes            |
| SQLite     | `TEXT`    | B-tree indexes                   |

## Set the Dialect

The dialect is **not auto-detected** — you always set it explicitly on
the config:

```go
audit.Config{
    Dialect: audit.PostgreSQL, // or audit.MySQL, audit.SQLite
}
```

Valid values are the constants `audit.PostgreSQL`, `audit.MySQL`, and
`audit.SQLite`. Custom dialects can be registered via
`audit.RegisterDialect` — see the [Dialect reference](/docs/api-reference/dialect).
